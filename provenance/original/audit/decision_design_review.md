# Independent review before comparative outcome evaluation

Reviewed20November2026: `protocol/design_before_data.md`, `src/replay.py` and `src/models.py`. This review used source definitions, code and synthetic data. It did not inspect Arkansas candidate answer tables or policy comparisons. The acquisition teams independently see source outcomes; the model developer remains separated from them. Literature snippets containing incidental Arkansas material were not used for policy development.

The proposed replay can estimate a useful, conditional decision quantity: selection regret among entries with measured, source-compatible yield and milling answers. It cannot estimate latent breeding value, prospective assay accuracy, actual technician time, or performance among entries without a measured answer. Recovering the original Uruguay files preserves the intended development/temporal-test/external-program structure; if those data had remained inaccessible, Arkansas-only temporal evaluation would have been a narrower study and would not support independent-program transfer.

**Time and split integrity.** All training, transformations, class histories and tuning for a harvest year must use strictly earlier harvest years. Unknown same-year laboratory ordering prevents using completed pools to update another pool in that year. A fixed final model trained through the development cutoff is the clean primary evaluation for the entire future test block; annual refits using every preceding test-year answer would assume access to unpaid assays and need a separate full-historical-information scenario. Repeated cultivars are permissible future records, but future cultivar names, aliases or descriptions cannot be used retrospectively to provide class or pedigree information. Report new versus returning candidates, and keep the previously exposed2025NERREC/Poinsett pool separate. Exact split years must come from the metadata audit, not outcome comparison.

**Public features and complete cases.** Field-yield normalization should use all compatible entries with positive observed field yield before restricting the answer key to measured milling records. The initial implementation recomputed ranks on whatever subset reached `public_view`; this could silently change the information set. The revised code preserves validated precomputed relative yield and rank. Its fallback calculation remains suitable for complete synthetic pools, but preparation must always supply the correct all-field features for real complete-case pools. Missing milling is never an imputed answer. Eligibility by answer availability changes the target population; compare missingness by year/site/stage/class and available public yield without pretending that missingness is random. Candidate and sample identity must prevent repeated checks, field replicates or reused samples from gaining multiple chances or crossing split boundaries.

**Fair feedback comparison.** The critical adaptive-minus-no-update contrast isolates use of the first batch's measured values only when predictor, public features, first-batch IDs/order, randomization, total budget and final tested-only shortlist rule agree. The reviewed branches implement this construction. Both may use paid answers to make the final shortlist; the no-update branch must withhold them only from ranking the untested second batch. Log the second-batch overlap as well as rank changes: rearranging untested ranks does not necessarily change acquired entries or utility. Compare adaptive against the development-selected strongest static comparator even if yield-first wins development. Tuning the adaptive predictor among model-based choices is acceptable when the stronger static benchmark is retained unchanged.

**Query boundary and alignment.** The initial query gate rejected repeated queries but allowed duplicate or wrong-size final shortlists; positional arrays could also be misaligned after sorting. The revised gate checks shortlist uniqueness/size and budget consumption; predictions are now indexed by row ID and replay aligns them. Scoring must independently validate pool size, exact k/B, unique tested IDs, complete query-event reconstruction and consistency with the answer key, rather than trusting saved counters. Required adversarial tests mutate all unrevealed outcomes and show unchanged prior actions; after batch one, only paid answers may affect the next action. At full budget, measured oracle recall must be1 and regret0 under the same deterministic tie rule. These tests establish software information flow, not a formal security boundary against arbitrary Python introspection.

**Mixed-model mathematics.** The random-pool-intercept covariance is `V = sigma2*I + tau2*Z*Z'`. The code's Woodbury inverse, grouped determinant and profiled restricted-likelihood objective are algebraically consistent for this model. An independent synthetic check used480candidates in24pools, seed731, and compared the implementation with `statsmodels.MixedLM(...).fit(reml=True, method='lbfgs')`. Maximum fixed-effect difference was3.29e-7; residual-variance difference2.10e-5; pool-variance difference0.00126; restricted-objective difference1.93e-5. Both optimizers converged. These are numerical engineering checks on synthetic data. Retain optimizer success, variance bounds, rank and convergence diagnostics for every real fit. The tiny information-matrix ridge is a numerical approximation, not permission to ignore a structurally unidentified design.

**Acquisition uncertainty and class fallback.** New-pool mixed predictions appropriately include residual and between-pool variation. Tree spread plus training residual/pool variation and the boundary score `s*phi((mean-threshold)/s)` are acquisition heuristics, not calibrated confidence intervals or a formally derived expected value of information. Residual-kernel shrinkage is likewise a transparent empirical correction rather than a Bayesian posterior update. Training-frequency class encoding fixes the original silent reference-class fallback for linear models; for trees, fractional one-hot input is an off-manifold heuristic unless predictions are explicitly marginalized over known classes. Missing/unseen class behavior must be named and tested. Uruguay genetic groups and Arkansas market grain classes are not automatically equivalent; verified common classes or an explicit unknown fallback are needed.

Before locking, the model owner proposed using only relative yield and yield rank for the direct-transfer primary, with a constant unharmonized class in both programs. I support this choice: it makes no unverified mapping between Uruguay germplasm groups and Arkansas market classes. Preserve the original source class in availability/subgroup reporting, and label any Uruguay class-aware model as a separate sensitivity. A constant class must also be used in feedback similarity for this common-feature primary.

**Weighting and uncertainty.** Equal-pool averaging targets the average decision pool; candidates, replicate plots and random seeds must not inflate the number of independent decisions. Random-policy seeds should be averaged within pool before paired contrasts. Candidate-weighted model fitting is a separate choice from pool-weighted model selection/evaluation and should be disclosed; it does not invalidate equal-pool scoring. Bootstrap paired differences with the same sampled harvest-year blocks for every policy and retain pool contributions within each sampled year. With few test years, present per-year effects and leave-one-year sensitivity beside descriptive intervals. Year-block resampling preserves within-year dependence but does not guarantee coverage under temporal trend or recurring site/cultivar dependence across years. No useful across-year inferential interval exists with one year. External-program results must stay separate from internal temporal results.

**Ties, units and precision.** A deterministic outcome-independent hash tie order shared with the oracle makes100%budget checks exact. Integer source rounding can change near-boundary oracle membership; report tie/rounding sensitivity with the same candidate perturbations for all policies. Such perturbations are sensitivity scenarios, not new independent outcomes or estimated measurement-error distributions. k/B rounding and actual testing fraction matter in small pools. Physical regret requires source-specific denominator and mass definitions; see `prior_art_units.md`. Do not pool unharmonized absolute units across programs. The measured output proxy and its oracle should be described as products of recorded candidate means unless paired plot-level products are separately computed.

**Interpretive decision.** Broad novelty is already excluded by the primary literature. A defensible positive result would require a stable, practically meaningful feedback gain over both the strong static baseline and the matched no-update policy, with temporal and independently acquired program evidence where feasible. Better recovery RMSE alone, a favorable random seed, a single pool or a cost claim based on entry queries does not establish this. Negative or inconclusive findings remain a valid technical report. Prospective laboratory validation would still require documented batch turnaround, physical sample availability, assay repeatability, actual costs and an independently scheduled comparison.

The model owner acknowledged and implemented the four initial findings about normalization, unknown-class behavior, gate validation and prediction alignment. This review does not certify later preparation/scoring code or final empirical results; those require the independent clean replay, event-log regeneration and source reconciliation specified by the user.
