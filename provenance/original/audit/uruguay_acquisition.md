# Uruguay acquisition and extraction audit

The four original files were recovered from the public Dryad-community Zenodo mirror at https://zenodo.org/records/8222856 on 2026-11-20. The mirror identifies DOI 10.5061/dryad.x69p8czn8 and the same 2023-08-07 release. Every downloaded file matches the SHA-256 and byte size published by current Dryad version 248051 (version 5). `uruguay_zenodo_acquisition.json` records exact file URLs, timestamps and checksums. This is the original dataset, not a second independent source.

## Public recovery routes

The current Dryad landing page, dataset/version/file APIs, DataCite metadata and linkset worked. Current and legacy file-stream downloads returned HTTP 403; documented API downloads returned HTTP 401 requiring a bearer token; public zip-assembly metadata returned HTTP 403. A same-session ordinary request did not recover downloads. The official interactive browser route was unavailable because the browser host could not be reached. No credentials, CAPTCHA solutions, authentication bypasses or external messages were used. Authorized local filename searches under Downloads, Documents and Research found no original data files. Public source previews worked only as truncated text and were never treated as full datasets; the README preview was unavailable.

The DataONE title/identifier searches found metadata copies but only linked back to Dryad. Zenodo exact DOI search returned zero hits; an exact title phrase returned the successful mirror. The alternative ReData DOI 10.60895/redata/2ZSCWL CSV and DDI were publicly downloaded. Its 150 columns are named VAR_1 through VAR_150 and all DDI labels repeat these codes. Its 93722 records and 1008 trials differ from the original release; without an authoritative mapping it was not used or counted as independent evidence. No column was inferred from plausible numbers. The ReData search record for the original title was only a harvested pointer with no hosted files. A public Colibri thesis download timed out and was not relied on.

The bounded recovery search used the exact DOI, exact title, filenames, author/program combinations, DataCite, DataONE, ReData and Zenodo. The access JSON files retain failures as well as successes. This is a task-specific acquisition audit, not a systematic review of all possible mirrors.

## Rights and source discrepancies

The original files are CC0-1.0 per both repositories and README. The README politely requests author contact to discuss possible collaboration; this is not a CC0 permission condition. No contact was sent. ReData is CC BY-NC-ND 4.0 and was not substituted. The README suggested-citation block contains a different DOI ending 2bvq83btg, although its title, persistent identifier, dataset sections and both repository manifests identify x69p8czn8. Cite the verified repository DOI rather than that inconsistent example. README version 1.0.0 is its document version; Dryad version 5 is the repository release version.

## Candidate and pool construction

`src/prepare_uruguay.py` checks all four source hashes before parsing. The original Phenotypes table contains 91636 records and 19 columns. Trials contains 996 records, unique by YEAR+TRIAL+LOCATION. Lines contains 20628 records, unique by LINE_ID. YEAR is harvest year; 2002 is absent. TRIAL identifies a trial within each year and location, so the final pool key is exactly harvest year+location+source trial. Source trial IDs are retained, including separate experiments and planting dates; grain class does not manufacture extra pools. EVALUATION_STAGE is preserved verbatim (including raw EF, E5, E6 and missing), because README's FE terminology does not justify silent recoding. Trial-level heritability, variance and CV are not model features.

One candidate is one LINE_ID in a pool. All original source rows are retained in the private plot archive. Nine exactly identical rows are marked and one copy retained for aggregation. Repeated candidate-within-block records remain observations because the archive lacks a unique subplot identifier: they may be repeated checks rather than duplicate errors. Each LINE_ID has one candidate result regardless of repeated checks or blocks. Equal weight is applied to the candidate's available source observations. Counts of observations and distinct blocks are both retained. Check status, physical assay counts, composite sampling and cross-replicate assay sharing cannot be identified reliably from coded line IDs and the available documentation; identical recovery values are flagged only in the private audit and do not prove shared assays.

Candidates require observed positive finite GY and observed PHR between 0 and 100 for retrospective eligibility. Missing outcomes remain missing, with explicit exclusions. No imputation, outcome-based favorable selection or performance comparison was performed. The main candidate quantity is mean observed GY times mean observed PHR/100. A separately preserved sensitivity uses the mean of products on the same measured plots, plus product of means on those matched plots; the latter separates sampling-set differences from covariance. Eligibility uses observed answers and therefore represents a paired-data subset rather than the entire breeding program. Public field-attribute comparisons between included/excluded entries are saved without recovery values.

## Definitions and limits

README defines GY in kg/ha and PHR as percentage whole milled kernels; it does not explicitly specify the PHR denominator or the grain-yield moisture adjustment. Monteverde et al.2018, DOI 10.2135/cropsci2017.09.0564, p.1521, explicitly defines PHR in the same INIA program as whole-milled-kernel weight divided by original rough-rice weight using a 100 g sample. That is supporting same-program evidence, not proof that every year 1997–2020 had identical measurement conventions. Candidate output is consequently labeled a rough-rice-basis proxy with unspecified moisture. Within-pool relative scoring is safer than asserting harmonized absolute mass across programs. No unknown moisture adjustment is applied.

GERMPLASM_TYPE is defined as germplasm and grain-quality type: Indica long grain; Tropical Japonica long grain; Temperate Japonica short/middle/heavy grain; Clearfield herbicide-resistant Indica/Tropical Japonica. The exact source class is retained and is not equated with Arkansas L/LA/M. Source classes may coexist in a source-defined trial. Plant height (soil surface to flag-leaf tip,cm) and days to flowering are ordinary field attributes. Milling recovery, chalkiness, stained grain, grain dimensions, amylose and alkali digestion are excluded from public modeling features.

## Outcome separation and rerun

The source/extraction auditor necessarily saw source outcomes. The model developer receives `derived/uruguay/public_features.csv` and metadata-only coverage tables to fix the split before opening allowed development labels. Hidden values are in `derived/uruguay/private_outcomes.csv` and `private_plot_records.csv`; no assertion of author-level or extractor-level blinding is made.

Run `.venv/bin/python src/acquire_uruguay.py` for public acquisition, or add `--offline` to verify cached originals. Then run `.venv/bin/python src/prepare_uruguay.py`. `uruguay_preparation_summary.json`, `uruguay_year_coverage.csv`, `uruguay_pool_metadata.csv`, `uruguay_coverage.csv`, `uruguay_duplicate_keys.csv`, the data dictionary and derived hash manifest provide the exact final counts.
