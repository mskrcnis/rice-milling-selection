# Post hoc action and breeder-display diagnostic plan

Dated 20 November 2026, after the original evaluation and manuscript were examined, and before running these new diagnostics. This is a descriptive, post hoc explanation of existing frozen results. It does not amend the original cohorts, budgets, models, rules, thresholds or confirmatory comparisons. The original project is read only.

## Action audit

Use the original run_a event log, frozen public candidates, frozen initial predictions, selected configuration and source candidate answer tables. Restrict primary summaries to Uruguay temporal evaluation and unseen Arkansas evaluation. At 25% compare two_batch with its identical-first-batch no_update control and separately with the locked mixed static rule; compare mixed with yield to substantiate the yield-consistent ranking. Report secondary adaptive_grid against adaptive_grid_no_update, trees_20 and mixed, plus trees_20 against mixed. Also show these prespecified contrasts at the previously reported secondary 40% budget to locate the one-pool feedback exception. Do not select additional budgets from these diagnostic results.

For every matched pool and budget, independently rebuild primary-value and final-shortlist regret from candidate means and the immutable tie hash. Rebuild pre/post-feedback complete untested rankings from frozen initial predictions, the actual first batch and its paid answers using the frozen update equation, clipping, bandwidth and selected shrinkage. Check these against stored rank-change counts and second batches. Distinguish changed rank positions, changed second-batch order versus membership, queried order versus set, final-shortlist order versus membership and measured regret. A matched second-batch comparison requires identical first-batch order and both policies to have two batches; a static rule has no second batch (not applicable). A rank-change count for an adaptive rule is its own pre/post-feedback comparison, not an invented matched-batch comparison against a static rule. Report the number of equal-regret pools with different queried or shortlisted sets. Use no inferential intervals or equivalence claims.

Recompute headline yield-first recall, best-entry recovery, regret and actual query fractions for every locked grid fraction from frozen candidates and logged queried sets. Average within pools and then equally across pools. Reconcile these with archived per-pool metrics. Split Arkansas descriptively into 2017–2020 historical-answer and 2021–2025 contemporaneous-answer subsets; report all contemporary-list rows, observed-field rows, paired candidates, pools, years, sites, incomplete pools, coverage and the exact query budget. These strata cannot identify a causal source of the program gap.

## Breeder display

Identify each pool's full-testing top k=ceil(.10*n) entries by the original measured product-of-means index and immutable tie rule. These are the reference entries; n counts eligible observed-answer candidates. Independently rank them in descending field yield, using the same tie rule, among eligible candidates. Let r be that one-based rank and B25=ceil(.25*n). The main two-panel display by program is a pool-equal empirical cumulative distribution of r/B25. Its marked boundary 1 is the exact rounded quarter-budget query boundary in every pool. Every reference entry has weight 1/(number_of_pools*k); each pool therefore contributes the same total weight. Show the aggregate curve, faint separate harvest-year curves and the exact 25%-budget recall. No confidence bands, hypothesis tests, country-level causal labels or fitted explanation are added. The horizontal axis is rank relative to the query count, not the fraction of candidates or a percent rank. The 4 Uruguay and 9 Arkansas harvest-year curves are descriptive, with recurring sites.

A companion display and CSV retain (a) eligible rank/n and (b) 1 minus the original all-field ascending average-rank percentile, whose denominator includes all compatible observed-field entries before answer restriction. This second measure preserves the frozen predictive feature, including average ties; it is not a sequential query position and its 25th-percentile boundary is not the integer-rounded budget. Report both denominators explicitly. Provide the historical/contemporary Arkansas split descriptively with complete-pool weights inside each subset; do not relabel the contemporary subset as new independent confirmation.

## Reproduction

Both scripts accept --source-project PATH and --output-dir PATH. Paths inside input and output manifests are relative. Scripts hash every consumed source file before and after execution, fail on changed input bytes, and record their own code and this plan hash. Original scientific modules are not imported and no fit or retuning occurs. Source-to-revision output isolation is required. Tables and figure data are portable; no original files, caches or logs may be written.
