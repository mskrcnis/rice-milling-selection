# Post hoc Arkansas rounding diagnostic: frozen before computation

This diagnostic does not change the original cohort, models, policies, exclusions, budgets, or primary comparison. It concerns the representational precision of integer Arkansas paddy yields and head-recovery percentages, using the previously documented closed half-unit intervals (±0.5 bu/ac and ±0.5 recovery percentage point). It does not model sampling or laboratory measurement uncertainty. Original files remain read-only.

All six original budgets are assessed in the 62 primary external pools (1,611 measured entries), the 19 historical pools (447 answers among 551 observed-field entries), and the 43 contemporary pools (1,164/1,164 complete entries). Each pool receives equal weight. Integer ceiling rules preserve original n, k and B, so actual testing fractions are explicitly reported.

For a fixed original yield-first query set Q, the final shortlist is the best k measured values inside Q, and the full-testing reference is the best k among all eligible entries. The product interval is attainable from the yield/HR rectangle. Raising a queried value cannot decrease the number of reference entries in Q or increase absolute or relative regret. Raising an unqueried value has the reverse effect. Therefore tested-low/untested-high and tested-high/untested-low corners attain the worst and best fixed-query metric values. Different budgets use different Q and thus different corners: these are pointwise envelopes, not an assertion that a single realization attains an entire envelope curve. First grid crossings of the upper and lower recall envelopes mark possible and guaranteed measured-grid threshold positions.

A separate joint scenario analysis recomputes yield-first query order and the output index using the same feasible realized paddy yield. Each candidate realization is reused at every budget, making each simulated budget curve internally coherent. The 20,000 independent uniform-within-rectangle scenario draws use fixed PCG64 streams derived from master seed20261120 and pool IDs. Uniform offsets are a transparent design choice, not a fitted error distribution. Reported quantiles and observed ranges are scenario summaries, never confidence intervals, p-values or guaranteed joint bounds. Four global yield/HR corners plus both budget-targeted corners for all six budgets provide16 symmetric predeclared feasible stress scenarios. None will be selected according to favorable results.

The historical/contemporary contrasts and comparisons with fixed original Uruguay recall/regret remain descriptive. Uruguay source precision is not perturbed and source absolute units are not pooled. Joint scenarios vary only observed-answer Arkansas candidates; missing outcomes remain missing.

Independent scalar calculations will check every fixed corner, every deterministic joint scenario, and eight predeclared random draws per pool at every budget. Small exhaustive synthetic vertex cases will validate the fixed-query extrema. Source hashes, this plan, and the diagnostic source will be locked before any real diagnostic computation.
